# makerSpaceOS – Projektübersicht
## Konzept
Das makerSpaceOS ist kein klassisches Betriebssystem, sondern ein kuratiertes Hardware-Ökosystem für Maker-Workshops und Hackdays. Ziel ist es, eine hochoptimierte Auswahl an Komponenten (Boards, Sensoren, Aktoren) bereitzustellen, die auf realen Verbrauchsdaten der letzten 3 Jahre basieren.

## Kernziele
- **Vermeidung von Waste:** Nur Teile, die wirklich gebraucht werden, kommen in das Standard-Kit.
- **Standardisierung:** Fokus auf Python/MicroPython und moderne Boards (Maker Pi RP2040 / Robo ESP32).
- **Einfachheit:** Preis und schneller Start stehen vor extremer Robustheit (Einweg-/Hackday-Modell).

## Aktueller Status
Das Projekt befindet sich im MVP-Seed Stadium. Die Modul-Struktur ist definiert, die finale Prüfung der Komponenten-Lieferbarkeit steht noch aus.
